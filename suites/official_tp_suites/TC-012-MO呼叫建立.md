## 0. 执行卡

【用例ID】TC-012 / 34.229-1 12.12 家族（12.12.1 带 preconditions / 12.12.2 不带 preconditions）

【来源】3GPP TS 34.229-1（本地抽取文件：`_extract/34229-1e70_ascii.txt`），Clause 12.12.1 / 12.12.2；关联 `TS 24.229` 5.1.3 / 6.1，`TS 24.173`，`TS 26.114`，Annex C.21，`TS 36.508` 4.5A.6.3-1。

【测试目的】按 34.229-1 12.12 验证 IMS 已注册 UE 能发起 MO MTSI 语音呼叫，正确完成 SIP/SDP 会话建立（含或不含 preconditions），并正常释放 BYE。

【优先级】P0

【前置条件/SS环境】
1. UE 已完成 IMS 注册（Annex C.2 / C.2a，GIBA 仅适用 GIBA）。
2. SS/P-CSCF 具备 MTSI 媒体能力，可回 100/183/180/200/ACK/BYE。
3. UE 与远端协商 AMR/AMR-WB 至少一种音频编码。
4. 正式一致性需按 `36.508` 4.5A.6.3-1 steps 1-14 执行；当前本地测试台用真实 pjsua 呼叫日志做字段级证据。

【测试步骤】
1. UE 发送 INVITE（首次 SDP offer），Request-URI 为被叫 URI，Route/Contact/P-Preferred-Identity/P-Asserted-Identity 按注册结果填充。
2. SS 回 100 Trying。
3. 按变体回 183 Session Progress（SDP answer），可选 PRACK/UPDATE。
4. SS 回 180 Ringing / 200 OK for INVITE。
5. UE 回 ACK。
6. UE 触发释放发 BYE，SS 回 200 OK for BYE。

【预期判据（逐消息检查）】
- INVITE：CSeq/Route/Contact 正确，SDP 至少含一个音频媒体；带 preconditions 时按 24.229 6.1.2 指示 local preconditions；不带 preconditions 时 SDP 不包含 precondition 信息。
- 媒体 SDP：AMR/AMR-WB/telephone-event、b=AS、RS/RR 限制按 26.114 7.3.1（RS<=4000 bps，RR<=3000 bps，或按规则置 0）。
- 100/183/180/200/ACK/BYE 按 SIP 事务规则；- ACK 在 2xx 后及时发送；BYE 携带正确 dialog 参数。
- 收到非 2xx 时按对应流程处理，不崩溃。

【通过标准】官方 TP 步骤和消息字段检查全部通过；本地字段级 PASS 不是 34.229-1 12.12 官方 SS Verdict。

【失败处理】记录失败步骤、抓包文件、UE 日志、SDP 字段偏离，关联缺陷 ID；正式一致性按 SS + 36.508 前置判 P/F。

## 3. 前置条件

- UE 已完成 IMS 注册。
- SS/P-CSCF 具备 MTSI 媒体能力，可回 100/180/183/200/ACK/BYE。
- UE 与远端/SS 协商音频编码（AMR/AMR-WB 至少一种）。

## 4. 验证流程

1. UE 发送 `INVITE`：
   - Request-URI 被叫 URI；
   - Route/Contact/P-Asserted-Identity 按注册结果填充；
   - SDP offer 含 `m=audio`、`a=rtpmap`、`b=AS/RS/RR`、可含 preconditions。
2. SS/被叫回 `100 Trying`。
3. SS/被叫回 `180 Ringing` 或 `183 Session Progress`（SDP answer）。
4. UE 收到 `200 OK`（INVITE）。
5. UE 回 `ACK`。
6. UE 触发释放，发 `BYE`。
7. SS 回 `200 OK` for BYE。

## 5. TP Verdict 判据（关键项）

- INVITE 行号/CSeq/Route/Contact 正确，SDP 至少一个音频媒体。
- INVITE `Request-URI`/`Via`/`Route`/`Contact`/ICSI/SRVCC 标签按 Annex A.2.1 条件适用；SDP 含 `m=audio`、`b=AS/RS/RR`、AMR 系列。
- 支持 preconditions 时 INVITE 含 `a=conf`；不支持时不带 precondition 信息。
- ACK 按时发送，RTP/RTCP 能建立或字段可判。
- BYE 携带正确 dialog 参数，释放后无残留会话。
- 错误处理：收到非 2xx 时按对应流程处理，不崩溃。
