## 使用方式

1. 复制 `official_tp_suites/_evidence/TC-026-031-evidence-manifest.template.json` 并填入真实证据。
2. 把 `source.type` 设为 `ss_conformance_instrument` 或 `accredited_lab`，并将 `qualified` 设为 `true`。
3. 每个 `tp_verdicts` 条目必须提供 `actual`，值只能是 `P` 或 `F`。
4. 运行：

```powershell
python -X utf8 runners\run_l1_evidence_adapter_026_031.py --manifest suites\official_tp_suites\_evidence\TC-026-031-evidence-manifest.json
```

5. 只有 L2 合格来源且所有 TP Verdict 行匹配时，报告才会出现 `OFFICIAL_PASS`；不匹配时出现 `OFFICIAL_FAIL`。
