## 当前边界

- `LOCAL_PASS` 只说明研发行为、字段或本地流程符合预期。
- `LOCAL_PASS` 不等于 `36.523-1` / `34.229-1` 官方一致性。
- 模拟 IMS 可以证明互通和流程行为，不能替代 IMS System Simulator。
- 当前没有真实 eNB/EPC/SS、IMS SS、SRVCC、SSAC、eCall 或一致性仪表，相关项保持 `RESTRICTED / L2_PENDING`。
- TC-013 缺官方无效 AKA 挑战真实注入；TC-025 的完整 AMR/EVS SCR 时序仍未满足；TC-034 缺具体 YD/T 和运营商清单。

## 三层验证定义

| 层级 | 做什么 | 当前状态 |
|---|---|---|
| L0 标准套件与官方 TP 骨架 | 锚定官方规范、章节、步骤、消息和 Verdict 判据 | 34 条文档齐备，32 条有正文行号锚 |
| L1 可执行测试框架 | 用本地日志、单测或模拟测试台执行字段/行为判据 | 已有 22 条证据入口，21 条 PASS/LIMITED_PASS |
| L2 真实一致性执行 | 由一致性 SS/仪表控制 UE 并按官方 TP 判 P/F | 未执行，保持 RESTRICTED |

“端到端”在这里指真实终端经 eNB/EPC 到 IMS 核心网及对端的完整链路；仅解析本地日志、单测注入或本机模拟都不能称为官方端到端一致性。
