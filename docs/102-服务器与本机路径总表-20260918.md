# 路径说明入口

## 仓库目录

```text
<REPO_ROOT>/
├── standards/official/        # 3GPP、ETSI、RFC 原文
├── suites/official_tp_suites/ # 34 条 TC 的官方 TP 骨架和测试步骤
├── registry/                  # TC、规范、章节和证据索引
├── runners/                   # 环境检查、证据检查和统一执行脚本
├── evidence/                  # 可复跑的日志、抓包和证据摘要
├── generated/                 # runner 生成的矩阵、状态和报告
└── docs/                      # 使用说明、路径说明和交接文档
```

仓库内路径都相对于 `<REPO_ROOT>`，换电脑或换服务器后不需要修改。
